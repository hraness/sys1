# Independent label review

The Codex integration owner reviewed all ten exact state payloads against the
unchanged discovery pack on 2026-09-27, before this experiment made any model
requests. The corpus worker selected and labeled these controls independently
of the separate context experiment's model results.

All ten primary labels are admitted as **clean for their named target rule**.
Other rules' scores may be retained, but those outputs have no reviewed labels.
The three actual diffs are ordinary presentation or provider-format changes;
the remaining seven controls replay source snapshots as additions.

The two Wordcell release states are **diagnostic only** and are physically
separate from the primary fixture file. Before the repair, a concurrent second
`release()` promise can settle while the first call's cleanup remains pending.
After the repair, both promises wait for the shared operation. The reproduction
uses the complete historical modules and their existing deterministic seam.

This behavior alone does not establish the frozen required-work rule's
misleading-success condition. The seam pauses after rename has removed the
original lock pathname, and the module returns `Promise<void>` without an
explicit success result. The original added regression tests heartbeat, not
concurrent release. The earlier state's `violation` field records the proposed
diagnostic hypothesis; it is **not an admitted positive label**. Both states
are excluded from primary metrics regardless of model output.

Bounded public-history research found no new unambiguous positive family for
these four exact rules. Several plausible repair titles proved to concern
failure cleanup, error diagnostics, validation, or representation compatibility
outside the rules' predicates. The set supports a small false-alarm check only.
It cannot estimate recall, qualify a rule, or demonstrate improved detection.
