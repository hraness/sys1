Run a check, inspect the result, then continue an optional review with the same files, command, and environment. List saved runs or inspect their execution records from the CLI.

Resume refuses changed inputs and uncertain interrupted steps. Run fresh required checks before delivery.

{{PORTFOLIO_HEADING:workflow-review-heading}}sys1-review · Sys1

Preview a batch of Git changes, check it against repository rules, and investigate the findings. Bundled rules cover empty catch blocks and removed test assertions in JavaScript and TypeScript.

Uses Jev, TypeSafe’s hosted decision model, or a local model. Experimental and advisory; keep your tests and ordinary review.

Set up code review →
{{PORTFOLIO_HEADING:workflow-completion-heading}}sys1-verify · Sys1

Compare a completion message with Git, linked pull requests, and live pages. Inspect whether work was committed, pushed, or made live. Missing evidence is marked unverifiable.

Uses Jev or a local model. Experimental and advisory; a result without contradictions does not prove completion.

Set up completion checks →

{{PORTFOLIO_HEADING:benchmarks-heading}}

The separate System One Skills package keeps noisy logs out of your agent’s context without a model. In a replay of 563 validation outputs, it returned 35.20% less text. Large outputs were shortened; small outputs stayed intact.

Read the measurement and its limits →

The September 20, 2026 study used one developer’s Codex and Devin sessions. It measured UTF-8 text bytes, not billed tokens or whole-task time.

Later task trials have not demonstrated whole-task token savings. Choose the compact-output skill for known noisy checks where a short status result is useful.

Browse all evaluations

{{PORTFOLIO_HEADING:how-heading}}

Sys1 also gives applications typed yes/no, choice, and score answers. Supply your context and questions; Sys1 routes the request and validates the response.

Choose Jev, TypeSafe’s hosted decision model, an experimental local Qwen model, or a compatible server. Hosted requests are opt-in. Local answers need evaluation on your own task.

Use the Node and Bun client, embed the router in Bun, or call the local HTTP gateway.

Read the API guide →

{{PORTFOLIO_HEADING:install-heading}}

Install Bun 1.3.14 or later, then the released CLI. ALGAL is included. Start with a saved check on macOS or Linux; configure a model when you want review or completion checks.

Latest release: v0.19.1 · MIT. Run sys1 --version to confirm installation, then follow the setup guide. For compact check output alone, install System One Skills.
