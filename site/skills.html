Evidence and what’s next.

One shipped skill. Ten research candidates. The result above applies to the noisy-check workflow.

How we measured the 82% reduction

Three of 24 archived Devin logs met the selection rule: known output of at least 8 KiB. The three used 9,731 raw text tokens. Compact output used 931, plus 774 counted skill, discovery, and invocation tokens: 1,705 total. The 8,026-token reduction is 82.48%, rounded to 82%, using o200k_base.

These were successful development checks, not independent whole-task trials. Native quiet reporters were not compared on those historical tasks. The 21 short cases would each add 258 first-use tokens if invoked unnecessarily. These are text-token estimates; whole-task and billed savings, retries, and follow-up reads were not measured. Calculation and calibration data. Read the detailed analysis of failures, follow-up costs, and native alternatives.

Costs, correctness, and limits

Long output is shortened only when the result is at least 50% and 4 KiB smaller. The full log is retained and omissions are explicit. All 24 replays passed ten preservation checks; 25 runtime tests covered capture, exits, faults, and installation. These test specific contracts, not better task outcomes.

The wrapper added 41.82 ms median and 48.37 ms p95 across 140 synthetic pairs on shared macOS arm64 with Node 24.20.0. This is overhead, not a speedup. Runtime methods and results.

All 14 selected replays in an unused cohort were short. None qualified; invoking the skill anyway would add 3,612 estimated first-use tokens. Discovery can also cost tokens on tasks where the skill is unused; that cost remains unmeasured. Unused-cohort findings.

A CI pilot found 128 status calls, but did not establish avoidable model polling. CI pilot findings.

  • system-one-diff: scoped diff review
  • system-one-digest: repository summaries
  • system-one-fetch: page extraction
  • system-one-research: source evidence
  • system-one-triage: decision routing
  • system-one-writing: draft checks
  • system-one-evolve: routing evaluation
  • system-one: skill selection

Their savings and task benefits remain unproven. Follow the catalog and research log. Admission requires independent correctness checks and comparisons on unseen complete tasks, including unused tasks and all overhead. The trial protocol requires at least 30 audited task/session clusters per scope; token savings cannot offset correctness failures or material latency regressions.

SYS1 routes typed decisions across local models and hosted services. System One Skills runs deterministic workflows without a SYS1 installation. Installing either does not configure the other.
