sysone
GitHub

One System One endpoint for every agent on your machine.

sysone runs a small local daemon that speaks the Jev-compatible decisions API — POST /v1/systemone — and routes each request across the models you can actually reach. Hosted Jev when you have a key. The cheapest, smallest local Jev-like model when you don't, or when you ask for one.

Typed decisions, not text

noul, choice, and score questions against a state — calibrated probabilities back, no generated prose. Built for routing, guardrails, and triage inside agent loops.

Smart model routing

Five policies from auto to local-only. Pin a model by name or backend/model; fallback runs cheapest-and-smallest local first.

Local by design

Loopback only. Credential lives in the environment, never the config file. No request bodies in logs. Your local runners stay processes you own.

Quickstart

export TYPESAFE_API_KEY=…
sysone up        # daemon on 127.0.0.1:13900
sysone status    # backend reachability

Point any System One client at http://127.0.0.1:13900/v1/systemone. Register local Jev-like models with sysone backend add.
