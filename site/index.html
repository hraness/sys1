01

Three local runtimes

GGUF via native llama.cpp, the 706K-param CUA-S1 option scorer in pure TypeScript, and Cactus Needle extraction via a bounded engine process. One registry, one store, one adapter per kind.

02

Route with intent

Prefer hosted, prefer local, restrict either side, or let auto use Jev first and the smallest available local model as fallback. Capability-aware: requests that exceed a backend's published limits are never dispatched to it. A pinned local-Nimble profile verifies the full wire contract before use.

03

Know every boundary

sysone doctor checks runtime, config, native backend, model structure, routing, and daemon ownership with stable JSON and closed exit codes.

Useful signals, honest semantics.

Builtin GGUF mode scores the model's complete first-token vocabulary while preserving exact Jev Noul, Choice, and fractional Score answer shapes. Specialist adapters disclose their contracts in response headers: the scorer returns true per-option distributions; needle's probabilities are an explicitly-labeled confidence approximation. A general GGUF is not presented as a calibrated Jev model; use trained System One weights when calibration is part of your contract.
